# Personal Website

This repository contains my personal static website, hosted with GitHub Pages:
https://thegreatwave21.github.io/

A single scrolling page in dark green: hero, About + focus areas, selected
work, what I'm currently exploring, and contact.

## Editing

- All text and links are plain HTML in `index.html` (one `<section>` each).
- Colours, fonts and sizes are the variables at the top of `style.css`.
- `script.js` only adds extras: header highlight, fade-in on scroll, card
  spotlight, hidden commands and a screensaver. The page works without it.
- `/barcona-systems/` and `/flow/` are separate project-page repos.
- After editing `style.css` or `script.js`, bump the `?v=` number on their
  links in `index.html` so browsers fetch the new version.

## Built with

- HTML
- CSS
- JS (vanilla, no build step)
- GitHub Pages
